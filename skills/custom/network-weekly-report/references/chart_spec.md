# 图表规格详细说明

## 总览

普通周报每个线路组生成 3 张 ECharts 5.5.0 折线图：
1. 带宽峰值 & 均值趋势（含利用率阈值线）
2. 峰值利用率 & 均值利用率趋势（含利用率阈值线）
3. 延迟趋势

VPDN 专线报表只生成 2 张图：
1. 带宽峰值趋势（含 35% 和 40% 阈值线）
2. 峰值利用率趋势（含 35% 和 40% 阈值线）

VPDN 专线报表不展示均值、均值利用率、延迟、延迟基线。

## 颜色规范

| 运营商 | 颜色代码 | 用途 |
|--------|----------|------|
| 电信 | `#5470C6`（蓝色） | 所有电信线路 |
| 联通 | `#EE6666`（红色） | 所有联通线路 |
| 移动 | `#91CC75`（绿色） | 所有移动线路 |

同一运营商的峰值和均值线使用相同颜色，通过线型区分。

## 线型规范

| 数据类型 | 线型 | 宽度 | 其他 |
|----------|------|------|------|
| 峰值 | 实线 `solid` | 2px | smooth, symbol=circle, symbolSize=5 |
| 均值 | 虚线 `dashed` | 1.5px | smooth |
| 阈值 | 虚线 `dashed` | 2px | 默认 80% 红色；VPDN 35% 橙色、40% 红色 |

## 图表 1：带宽峰值 & 均值

- **Y轴**：Mbps，最大值必须等于当前线路组内所有线路、所有日期的最大 `bandwidth_mbps`。不得按 `max_peak`、阈值线或其他动态值放大
- **每条线路**：2 条线（实线=峰值，虚线=均值）+ 阈值 markLine
- **VPDN**：只画峰值线，不画均值线
- **阈值 markLine**：普通周报默认值为 `该线路当前带宽 × 80%`；VPDN 专线报表使用 `该线路当前带宽 × 35%` 和 `该线路当前带宽 × 40%`
- **阈值标签位置**：`insideEndTop`

## 图表 2：利用率

- **Y轴**：百分比，固定最大值 100
- **每条线路**：2 条线（实线=峰值利用率，虚线=均值利用率）
- **VPDN**：只画峰值利用率线，不画均值利用率线
- **阈值 markLine**：在第一个 series 上画。普通周报默认 80；VPDN 专线报表画 35 和 40 两条线

## 图表 3：延迟

- **Y轴**：ms，最大值 = `max(所有线路延迟) × 1.3`，至少为 1
- **每条线路**：1 条实线（延迟）
- **不画基线**

```javascript
    containLabel: true

    type: 'category',

    type: 'value',

```

## 图表容器

- 高度 420px，宽度 100%
- 边框 1px solid #e8e8e8，圆角 6px
- 背景 #fafbfc

## 逐日明细表

普通周报每组图表下方，列为：

```
日期 | [每条线路]: in_peak, out_peak, max_peak, in_avg, out_avg, max_avg, 峰值利用率, 均值利用率, 延迟ms, 峰值基线, 延迟基线, 带宽
```

- 表头 sticky 固定（position: sticky, top: 0, z-index: 1）
- 字体 12px，单元格居中，nowrap
- 最大高度 450px，横向+纵向可滚动
- 标题行背景 #f0f3f8，hover 行 #f5f8ff
- `bw_peak_baseline_mbps` 和 `latency_baseline_ms` 只在表格中展示，不进入任何曲线 series
- VPDN 专线报表逐日明细只展示 `max_peak` 和 `峰值利用率`

## 总结汇总表

| 列 | 说明 |
|----|------|
| 线路 | 线路名 |
| 运营商 | 电信/联通/移动 |
| 带宽 | 当前带宽档位 |
| 最大峰值 | 全周期 max_peak 最大值 |
| 最大峰值利用率 | 全周期峰值利用率最大值 |
